L'activation de votre abonnement au bot de prédiction FIFA virtuel 1xBet est un processus simple et entièrement automatisé via Telegram. En moins de cinq minutes, vous accédez à des prédictions alimentées par l'intelligence artificielle, directement dans votre messagerie. Suivez les étapes ci-dessous pour commencer.

## Étapes d'Activation

<Steps>
  <Step title="Taper /subscribe dans le bot">
    Ouvrez votre conversation avec le bot sur Telegram et envoyez la commande suivante :

    ```text
    /subscribe
    ```

    Le bot vous répondra immédiatement avec un menu interactif présentant les formules disponibles.
  </Step>

  <Step title="Sélectionner votre plan">
    Choisissez la formule qui correspond à vos besoins parmi les trois options proposées :

    - 🌱 **Starter** — 9,99 €/mois
    - ⚡ **Pro** — 24,99 €/mois
    - 👑 **VIP** — 49,99 €/mois

    Appuyez sur le bouton correspondant au plan souhaité pour passer à l'étape suivante. Si vous n'êtes pas encore certain de votre choix, consultez la page [Comparer les Plans](/subscription/plans) pour vous aider à décider.
  </Step>

  <Step title="Choisir votre méthode de paiement">
    Sélectionnez votre méthode de paiement préférée parmi celles disponibles :

    - 💰 **Cryptomonnaies** — Bitcoin, USDT, Ethereum
    - 📱 **Mobile Money** — Orange Money, MTN Money, Wave
    - 💳 **Carte Bancaire** — Visa, Mastercard
    - 🏦 **Virement Bancaire** — Traitement sous 24h

    Pour plus de détails sur les options de paiement, consultez la page [Méthodes de Paiement](/subscription/payment).
  </Step>

  <Step title="Confirmer le paiement">
    Suivez les instructions affichées par le bot pour finaliser votre paiement. Selon la méthode choisie :

    - **Crypto** : Scannez le QR code ou copiez l'adresse de dépôt, puis envoyez le montant exact.
    - **Mobile Money** : Composez le code USSD indiqué ou validez via votre application mobile.
    - **Carte bancaire** : Saisissez vos coordonnées sur la page de paiement sécurisée.
    - **Virement** : Effectuez le virement selon les coordonnées bancaires communiquées et attendez la confirmation (jusqu'à 24h).

    Une fois le paiement reçu et confirmé par notre système, l'activation est déclenchée automatiquement.
  </Step>

  <Step title="Accès activé automatiquement">
    Dès que votre paiement est confirmé, le bot vous envoie un message de confirmation et votre abonnement est immédiatement actif :

    ```text
    ✅ ABONNEMENT ACTIVÉ
    ━━━━━━━━━━━━━━━━━
    🏆 Plan : PRO
    📅 Valide jusqu'au : 15/02/2025
    🤖 Statut : ACTIF

    Tapez /predict pour commencer !
    ```

    Vous pouvez désormais utiliser la commande `/predict` pour recevoir vos premières prédictions et commencer à parier.
  </Step>
</Steps>

## Renouvellement Automatique

Par défaut, votre abonnement est renouvelé **automatiquement** à la date d'expiration pour garantir une continuité de service sans interruption. Le montant correspondant à votre plan est prélevé selon la méthode de paiement enregistrée.

**Pour désactiver le renouvellement automatique**, envoyez la commande suivante dans le bot :

```text
/cancel_renewal
```

Le bot vous confirmera l'annulation du renouvellement. Votre abonnement restera actif jusqu'à la fin de la période en cours, sans aucun prélèvement supplémentaire.

<Note>
  L'annulation du renouvellement automatique ne résilie pas immédiatement votre abonnement. Vous continuez à bénéficier de toutes les fonctionnalités de votre plan jusqu'à la date d'expiration indiquée.
</Note>

## Vérifier Votre Abonnement

À tout moment, vous pouvez consulter le statut et les détails de votre abonnement en envoyant la commande `/balance` dans le bot :

```text
/balance
```

Le bot vous retournera un récapitulatif de votre abonnement actif :

```text
📋 MON ABONNEMENT
━━━━━━━━━━━━━━━━━
🏆 Plan actuel : PRO
📅 Date d'expiration : 15/02/2025
🔄 Renouvellement auto : ACTIVÉ
🎯 Prédictions utilisées aujourd'hui : 12
⚡ Statut : ACTIF
```

Cette commande vous permet également de vérifier le nombre de prédictions consommées dans la journée (pour le plan Starter) et de vous assurer que votre abonnement est bien en ordre avant une session de paris.

<Note>
  L'activation de votre abonnement est **instantanée** dès que le paiement est confirmé par notre système. Pour les paiements par cryptomonnaie et Mobile Money, la confirmation intervient généralement en moins de deux minutes.
</Note>

En cas d'utilisation frauduleuse ou de partage détecté, le compte peut être suspendu sans remboursement. Gardez vos identifiants confidentiels pour protéger votre accès et la sécurité de vos données.
</Warning>
